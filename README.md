# RabcanTV – vydania

Hotové APK aplikácie RabcanTV pre Android TV. Zdrojový kód je v súkromnom repozitári.

**Prvá inštalácia** (napr. cez appku Downloader na TV):
https://github.com/MilanR11/rabcan-tv-releases/releases/latest/download/RabcanTV.apk

Ďalšie verzie si appka nájde sama: Nastavenia → Aktualizácia.

## Windows

Inštalátor (stačí stiahnuť a spustiť, administrátor netreba):
https://github.com/MilanR11/rabcan-tv-releases/releases/download/desktop-v0.1.0/RabcanTV-Setup-0.1.0.msi

Ďalšie verzie si appka nájde sama: Nastavenia → Aktualizácia. Vydania pre Windows majú značku `desktop-v…`.
